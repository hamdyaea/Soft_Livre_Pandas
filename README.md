## Maintenance and regression tests

Maintainer: Hamdy Abou El Anein — hamdy.aea@protonmail.com

Install `requirements.txt` in a virtual environment. Run `python3 -m unittest -v` from the repository root. CSV inputs now resolve relative to each example, and generated row numbers adapt to the data length. All 31 chapter programs are executed from a temporary unrelated working directory by the regression suite, with plots using the noninteractive Agg backend. Original chapter organization is retained.
